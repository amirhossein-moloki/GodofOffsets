# R6 Professional Offset Dumper

این پروژه یک ابزار پیشرفته و حرفه‌ای برای استخراج آفست‌های بازی **Rainbow Six Siege** است که با استفاده از C++20 و با تمرکز بر امنیت و دقت طراحی شده است.

## ✨ ویژگی‌های کلیدی
- **Zydis Integration:** محاسبه دقیق آدرس‌های RIP-Relative با استفاده از دیس‌اسمبلر Zydis.
- **Stealth Mode:** پشتیبانی از متد Handle Elevation برای دور زدن شناسایی BattlEye در سطح User-Mode.
- **High Performance:** اسکن حافظه به صورت Buffer-Chunked و Multi-threaded.
- **JSON Based:** مدیریت آسان پترن‌ها از طریق فایل `signatures.json` بدون نیاز به کامپایل مجدد.
- **Auto Export:** تولید خودکار فایل `offsets.h` برای استفاده در پروژه‌های دیگر.

## 🚀 راهنمای کامپایل (CMake)
برای ساخت پروژه، از دستورات زیر استفاده کنید (مطمئن شوید CMake و کامپایلر MSVC نصب هستند):

```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

## 🛠 نحوه استفاده
1. بازی Rainbow Six Siege را اجرا کنید.
2. برنامه `UniversalOffsetDumper.exe` را با دسترسی Administrator اجرا کنید.
3. در رابط کاربری، نام پروسس را وارد کرده (پیش‌فرض `RainbowSix.exe`) و روی یکی از دکمه‌های **Attach** کلیک کنید.
4. روی **Run Scanner** کلیک کنید تا تمام آفست‌ها استخراج شوند.
5. برای ذخیره نتایج، روی **Export offsets.h** کلیک کنید.

## 🛡 راهنمای تست ایمن (Offline Testing)
برای جلوگیری از بن شدن در حین تست و توسعه، بازی را در حالت آفلاین اجرا کنید:
1. اینترنت خود را قطع کنید.
2. در تنظیمات Ubisoft Connect، حالت "Always start in offline mode" را فعال کنید.
3. بازی را اجرا کنید. در این حالت BattlEye فعال نخواهد شد و می‌توانید با خیالی آسوده از متد **Standard Attach** استفاده کنید.

## ⚠️ هشدار امنیتی
این ابزار صرفاً برای اهداف **آموزشی و تحقیقاتی** طراحی شده است. استفاده از آن در سرورهای Live بازی Rainbow Six Siege منجر به شناسایی توسط BattlEye و مسدود شدن قطعی حساب کاربری شما خواهد شد. نویسنده هیچ مسئولیتی در قبال سوءاستفاده از این ابزار ندارد.

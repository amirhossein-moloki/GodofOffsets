# Universal Offset Dumper (Native & Stealth) 🛡️

یک ابزار مهندسی معکوس حرفه‌ای، Native و فوق‌سریع برای ویندوز که با هدف استخراج آفست‌ها، اسکن حافظه و تحلیل ساختارهای داده در بازی‌ها و نرم‌افزارها توسعه یافته است. این پروژه با استفاده از **C++20** و کتابخانه‌های قدرتمندی نظیر **Zydis** و **Dear ImGui** ساخته شده است.

## ✨ ویژگی‌های کلیدی
- **Zydis Engine:** رمزگشایی هوشمند دستورات x86/x64 و محاسبه خودکار آدرس‌های **RIP-Relative** (بسیار حیاتی برای بازی‌های مدرن).
- **SIMD Optimized:** استفاده از دستورات SSE4.2 و AVX2 برای اسکن بسیار سریع حافظه (AOB Scan).
- **Stealth Architecture:** لایه انتزاعی برای استفاده از متدهای مخفی (مانند Kernel-mode یا Handle Hijacking) جهت دور زدن آنتی‌چیت‌ها.
- **Asynchronous Processing:** تمامی اسکن‌ها در ترد‌های جداگانه انجام می‌شود تا رابط کاربری (UI) فریز نشود.
- **Multi-Arch Support:** پشتیبانی کامل از پروسس‌های ۳۲ بیتی (x86) و ۶۴ بیتی (x64).

## 🚀 راهنمای نصب و اجرا (قدم به قدم)

### ۱. کلون کردن پروژه
ابتدا ترمینال (یا CMD) را باز کرده و دستور زیر را وارد کنید:
```bash
git clone https://github.com/your-username/UniversalOffsetDumper.git
cd UniversalOffsetDumper
```

### ۲. پیکربندی و ساخت (Build)

#### روش اول: استفاده از Visual Studio (پیشنهادی)
1. پوشه پروژه را در Visual Studio باز کنید.
2. ویژوال استودیو به طور خودکار فایل `CMakeLists.txt` را تشخیص می‌دهد.
3. از منوی بالا، نوع ساخت را روی **Release - x64** قرار دهید.
4. کلید `Ctrl+Shift+B` را بزنید تا پروژه کامپایل شود.
5. فایل اجرایی در پوشه `out/build/...` ساخته می‌شود.

#### روش دوم: استفاده از خط فرمان (Command Line)
```bash
mkdir build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release
```
پس از اتمام، فایل `UniversalOffsetDumper.exe` در پوشه `Release` ایجاد خواهد شد.

## 🛠 راهنمای استفاده از بخش‌های مختلف

### تب Process (اتصال به برنامه)
در این بخش نام پروسس هدف (مثلاً `winmine.exe`) را وارد کنید. دو حالت برای اتصال وجود دارد:
- **Standard:** استفاده از توابع استاندارد ویندوز.
- **Stealth:** تلاش برای باز کردن پروسس با دسترسی‌های محدودتر و تکنیک‌های مخفی (برای دور زدن مانیتورینگ آنتی‌چیت).

### تب Memory Scanner (جستجوی مقادیر)
مشابه Cheat Engine، می‌توانید انواع داده (Int, Float, String, AOB) را جستجو کنید.
1. نوع داده را انتخاب کنید.
2. مقدار را وارد کرده و **First Scan** را بزنید.
3. مقدار را در بازی تغییر دهید و با **Next Scan** لیست را فیلتر کنید.

### تب Signature Scanner (استخراج آفست‌ها)
این بخش آفست‌های تعریف شده در فایل `signatures.json` را استخراج می‌کند.
- دکمه **Run Signatures Scan** را بزنید تا تمامی پترن‌ها در حافظه بازی جستجو شوند.
- اگر پترن از نوع **Relative** باشد، برنامه به طور خودکار با استفاده از دیس‌اسمبلر Zydis، آدرس نهایی را محاسبه می‌کند.
- با دکمه **Export offsets.h** می‌توانید خروجی را مستقیماً برای استفاده در کد چیت خود دریافت کنید.

### تب Pointer Scan (پیدا کردن زنجیره اشاره‌گر)
برای پیدا کردن آدرس‌های پویا که با هر بار اجرای بازی تغییر می‌کنند:
1. آدرس پیدا شده در مرحله اسکن حافظه را وارد کنید.
2. عمق جستجو (Depth) و حداکثر آفست را تعیین کنید.
3. دکمه شروع را بزنید تا زنجیره‌های اشاره‌گر پایدار (Static Pointer Chains) پیدا شوند.

## 📂 افزودن امضاهای جدید (signatures.json)
برای اضافه کردن آفست‌های جدید، فایل `signatures.json` را ویرایش کنید:
```json
{
    "name": "GameManager",
    "pattern": "48 8B 05 ? ? ? ? 48 8B 48 08",
    "module": "winmine.exe",
    "offset": 0,
    "relative": true,
    "description": "توضیحات مربوط به آفست"
}
```
- **pattern:** امضای هگزادسیمال (از `?` برای بایت‌های متغیر استفاده کنید).
- **relative:** اگر آدرس در دستوراتی مثل `LEA` یا `MOV` به صورت RIP-relative است، این را `true` بگذارید.

## ⚠️ هشدار امنیتی (Anti-Cheat)
این ابزار در حالت **Standard Mode** توسط آنتی‌چیت‌هایی مثل **BattlEye** یا **Easy Anti-Cheat** شناسایی می‌شود. برای استفاده در بازی‌های دارای آنتی‌چیت فعال:
1. بازی را در حالت آفلاین یا بدون آنتی‌چیت اجرا کنید.
2. یا ماژول **Kernel Driver** خود را به بخش `StealthMode` در کد منبع اضافه کنید.
